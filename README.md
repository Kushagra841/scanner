# Barcode Scan Logger

A single-page tool for packing staff. A USB barcode scanner types the code into the page, and each scan is saved with the packer's name and the exact date and time, down to the millisecond.

- Works in any browser, with no install and no server
- Warns when a code has already been scanned
- Admin PIN needed to delete a scan or clear the list
- Download all scans as an Excel-ready CSV file

Scans are stored in each PC's own browser, so use the same link and browser each day and download the CSV regularly.
